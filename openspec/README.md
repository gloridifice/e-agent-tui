# Retired OpenSpec history

> Status: Historical — deprecated
> Authority: None. The entire `openspec/` tree is retained for historical reference only.

All new changes use the [Doco skill](../.agents/skills/doco/SKILL.md) and live under `doco/changes/`. Current documentation and authority rules start at [doco/architecture.md](../doco/architecture.md) and the [documentation index](../doco/README.md).

## Retained material

- `specs/` — former main specifications, no longer current normative contracts.
- `changes/` — former proposals, deltas, designs, tasks, and archived deliveries.
- `schemas/` and `config.yaml` — retired CLI configuration and templates, not a workflow to maintain or invoke.
- [Former Lite workflow](workflow.md) — historical instructions; commands are not current project guidance.
- `integrations/skills/` — former OpenSpec skills removed from active discovery and retained without rewriting their historical instructions.

Do not create, execute, validate, synchronize, or archive new work with OpenSpec. Old status labels and imperative instructions inside these records describe the former workflow and cannot override this retirement notice or current Doco policy.

Consult individual records only when historical context is explicitly needed. Do not bulk-copy them into current specs. Any requirement adopted into `doco/specs/` needs explicit review and approval against current contracts, implemented behavior, and intended compatibility; the workflow transition itself does not change application behavior.
