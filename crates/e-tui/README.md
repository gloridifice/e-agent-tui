# e-tui

`e-tui` is the runtime-neutral terminal frontend shared by [`e-dsh`](https://crates.io/crates/e-dsh) and [`e-pi`](https://crates.io/crates/e-pi). It provides normalized agent contracts, interaction state, rendering, terminal input, and the shared runtime controller for the [`e`](https://github.com/gloridifice/e) project.

The library is currently experimental. Its public Rust API may change between `0.1.x` releases.
